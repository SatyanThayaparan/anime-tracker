# Shiori icons

Bookmark mark for **Shiori** (栞) — solid forest field, cream ribbon bookmark, rust cord/tassel. Flat and readable at toolbar size.

| File | Use |
|------|-----|
| `icon16.png` / `icon48.png` / `icon128.png` | Chrome extension toolbar + store |
| `icon.svg` | Vector source for crisp redraws |
| `icon-art-reference.jpg` | Painted reference used for the PNG set |
| `icon-source.png` | 512px raster copy of the painted art |

Regenerate PNGs from the painted source with a high-quality downscale when the art changes.
